## 업무분담

1. 뉴스 수집 및 저장, 프로젝트 템플릿 구조화 및 제공
    - 프로젝트 진행하기 위한 구조(템플릿) 생성 -> 팀원들에게 제공
    - 네이버 뉴스 API, Selenium 크롤링 사용 -> raw/clean 분리 저장
      - 이슈: Selenium ARM서버 미지원, AMD64서버에서 설치해서 진행함.
    - 중복 뉴스는 skip / upsert 처리 (설정에서 선택하도록 지원)
      - 같은 뉴스는 URL로 판단
    - 뉴스는 최대 100건까지 조회하도록 (네이버 정책상 한 번에 100개까지)
      - 그 이상 조회하려면 페이지네이션쓰면 되는데 귀찮으니 생략

2. AI 기반 뉴스 요약
    - 저장된 뉴스 본문을 AI API에 전달하여 요약문 생성 및 저장

3. AI 기반 인사이트 분석
    - 일정 기간 또는 카테고리의 뉴스를 종합 분석하여 트렌드, 핵심 키워드, 주요 이슈를 도출
    - 분석 결과가 저장되고 조회 가능

4. 시각화 및 리포트 생성
    - 카테고리별 뉴스 분포, 일자별 수집 추이 등 차트로 시각화
    - 품질 지표와 TOP N 집계가 포함된 리포트 생성
    - 결과를 CSV, 엑셀 파일로 내보내기
