## 업무분담

1. 뉴스 수집 및 저장, 프로젝트 템플릿 구조화 및 제공
    - 프로젝트 진행하기 위한 구조(템플릿) 생성 -> 팀원들에게 제공
    - 네이버 뉴스 API, BeautifulSoup 크롤링 사용 -> raw/clean 분리 저장
    - 중복 뉴스는 skip / upsert 처리 (설정에서 선택하도록 지원)
      - 같은 뉴스는 URL로 판단

2. AI 기반 뉴스 요약
    - 저장된 뉴스 본문을 AI API에 전달하여 요약문 생성 및 저장

3. AI 기반 인사이트 분석
    - 일정 기간 또는 카테고리의 뉴스를 종합 분석하여 트렌드, 핵심 키워드, 주요 이슈를 도출
    - 분석 결과가 저장되고 조회 가능

4. 시각화 및 리포트 생성
    - 카테고리별 뉴스 분포, 일자별 수집 추이 등 차트로 시각화
    - 품질 지표와 TOP N 집계가 포함된 리포트 생성
    - 결과를 CSV, 엑셀 파일로 내보내기

## 개인 메모

* Selenlum ARM 서버 미지원 -> 이에 따라 AMD64 서버에서 설치하여 진행
 BeautifulSoup 속도가 훨씬 빠름. 순수 Python이라 arm에서도 가능. 다만 JS 실행이 안되는게 단점임.

* 크롤링은 확실히 상당히 느림. 그럼에도 쓰는 이유는 JS처럼 실제로 클릭되어야 하는 경우는 API 방식으로 안되기 때문에 크롤링으로 수집해야 함.

* 네이버 뉴스는 최대 100건까지 한 번에 요청 가능, 따라서 페이지네이션 기법을 통해 그 이상을 가져올 수 있지만 과제이니 그냥 100건까지 제한을 둔다.

## Git 협업 방법

**main에 직접 push하지 말고, 브랜치 만들어서 PR 올려주세요.** 브랜치 이름은 알아서 편한 대로 지으면 됩니다.

**0. 최초 1회** (초대 메일 수락 후)

```bash
git clone https://github.com/rla8127/codyssey-team-project-2B.git
cd codyssey-team-project-2B
```

**1. 작업 시작**

```bash
git checkout main
git pull origin main
git checkout -b 브랜치이름 # 알아서 편한대로
```

**2. 작업 후 push**

```bash
git add .
git commit -m "커밋 메시지"
git push -u origin 브랜치이름
```

**3. PR 생성**

push하면 터미널에 뜨는 `pull/new/...` 링크를 클릭하거나, GitHub 리포 페이지의 **Compare & pull request** 버튼을 누릅니다. 제목/내용 쓰고 **Create pull request** 클릭하면 끝.

**4. 수정 요청 받으면** — 같은 브랜치에서 고치고 다시 push하면 PR에 자동 반영됩니다. (PR 새로 안 만들어도 됨)

**5. Merge된 뒤 쵯니화**

```bash
git checkout main
git pull origin main
```
